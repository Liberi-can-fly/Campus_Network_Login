# Campus_Network_Login——适用于韶关松山职业技术学院（莲花校区）的校园网自动登录脚本

小刻也能看懂的README


在某些未知的情况下连接校园网可能无法弹出登录页面，此脚本可以在绕过登录页面的情况下登录校园网，
同时此脚本也具有断网自动重连、设置登录设备类型(神人校园网会把Linux当手机),修改MAC地址等功能。
您也可以将此脚本用于openwrt等软路由。

## 食用方法
1. 根据你的系统安装 **python3** 和 **pip**。
    * 建议添加到环境变量 *Add to PATH*
2. 安装依赖：
    ```bash
   $ pip install requests 
   ```
3. 在 **login.py** 中填写账号和密码等信息。
    * 为了防止有小刻不会打开login.py，不会填账号和密码，小刻在此提醒您login.py可以用windows自带的记事本打开，账号密码要填在双引号内，不要忘记保存！！！
    * vlan可以为空
    * **注意True和False的大写**
4. 运行 **login.py**
    ```bash
    $ cd Campus_Network_Login/        # 在终端中打开文件夹
    $ python login.py                 # 运行
    ```
